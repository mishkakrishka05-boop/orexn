# NERU · библиотека проекта

Материалы для независимой концепции редизайна NERU. Начало работы в Codex зависит от задачи.

| Задача | Материал |
|---|---|
| Найти товар и его изображение | [Каталог по пяти категориям](catalog/README.md) |
| Найти слова бренда | [Три раздела ассортимента](sources/sections.md) · [О компании](sources/NERU%20—%20исходные%20тексты%20о%20компании.md) · [Курут и ранние материалы](sources/NERU%20—%20ассортимент%20исходные%20материалы.md) |
| Продумать подачу, тексты и движение | [Концепция сайта](concept/README.md) |
| Посмотреть три эскиза | [Визуальные направления](concept/Визуальные%20концепции/) |

Исходники предоставлены пользователем со страниц NERU. В каталоге указана позиция карточки на скриншоте. Эскизы служат для обсуждения дизайна. Для новых поступлений сохраняем оригинал в sources и добавляем подпись и привязку в каталог. Редакторские версии текстов пишем отдельно после сбора материала.
