# Как подать NERU

**Замысел пользователя.** На первом экране падают орехи, сухофрукты и сладости. Хочется передать изобилие, объём и ощущение дорогого подарка. При прокрутке открываются коллекции: подарки → сладости → орехи → сухофрукты. Для экопродуктов место пока открыто. При выборе набора он приближается, появляется описание. Вращение требует дополнительных ракурсов или модели.

**Таджикская культура в тексте.** Пользователь хочет сделать её частью подачи. В самих материалах есть три точки опоры: рассказ бренда о значении названия NERU, названия реальных подарочных наборов и описание национальных сладостей. Для вступления можно взять историю названия из архива «О компании». В коллекции сладостей — показать «Камушки» крупно и рядом назвать продукт словами с карточки. В подарках — дать сначала название набора, затем его реальную форму и рисунок секций. Это редакторские предложения. Происхождение ингредиентов, традиции дарения и значения орнаментов требуют отдельных источников.

**Пример перехода, черновик:** «От ореха в сахарной оболочке до целого подарочного набора».

**Визуальные опоры.** Для водопада использовать [фактуры смеси](../sources/neru-about-waterfall-reference-02.png), для формы и деления наборов — [четыре реальные карточки](../sources/gifts-grid.png). Фото мужчины исключено из концепции по решению пользователя. Три существующих эскиза исследуют глубокий зелёный, тёмную кинематографичную палитру и яркое фисташково-абрикосовое направление. Выбор открыт.
